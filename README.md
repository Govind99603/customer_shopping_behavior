# 📌 Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 customer purchases** across multiple product categories.

The objective is to identify:

* Customer spending patterns
* Product preferences
* Revenue drivers
* Subscription behavior
* Customer loyalty segments
* Discount effectiveness

The project follows a complete analytics workflow:

```text
Raw Dataset
     │
     ▼
Python Data Cleaning
     │
     ▼
Feature Engineering
     │
     ▼
PostgreSQL Database
     │
     ▼
Business Analysis using SQL
     │
     ▼
Interactive Power BI Dashboard
     │
     ▼
Business Recommendations
```

# 🔍 Data Preparation & Cleaning

The dataset was cleaned and transformed using Python.

### Steps Performed

✅ Loaded dataset using Pandas

✅ Checked data structure using:

```python
df.info()
df.describe()
```

✅ Handled missing values

* 37 missing values found in Review Rating
* Imputed using median rating per product category

✅ Standardized column names

```text
Camel Case → snake_case
```

### Feature Engineering

Created:

* `age_group`
* `purchase_frequency_days`

### Data Consistency Check

Identified redundancy between:

* discount_applied
* promo_code_used

Removed:

```text
promo_code_used
```

to improve data quality.

# 💡 Key Business Insights

### Customer Insights

* Loyal customers dominate the customer base.

### Product Insights
